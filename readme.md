# SP Web Solutions — Client Dashboard

Full-stack client dashboard application.

## Tech stack

| Layer    | Stack                          |
| -------- | ------------------------------ |
| Frontend | React, Vite, Tailwind CSS      |
| Backend  | Node.js, Express               |
| Database | PostgreSQL                     |
| Auth     | JWT                            |
